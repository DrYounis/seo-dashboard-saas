🗓️ Schedule & Configuration

Set up automatic weekly R&D cycles

⏰ Cron Schedule

Add this to your crontab to run every Monday at 8am:

0 8 * * MON cd "/Volumes/Elements/AG/ai deveopers" && python rd_system.py >> rd_cron.log 2>&1

Run crontab -e and paste the above line.

🔑 Environment Variables
GROQ_API_KEYFor LLM trend analysis (free at console.groq.com)
GITHUB_TOKENHigher GitHub API rate limits
SENDGRID_API_KEYEmail weekly reports
REPORT_EMAILWhere to send weekly reports
📋 Manual Commands
# Run R&D cycle now python rd_system.py --force # Start dashboard server python rd_api.py # View latest report cat rd_reports/$(ls rd_reports/ | tail -1)
